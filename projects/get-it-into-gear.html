Get It Into Gear

Home | Projects and Class Notes | Documentation

This program works with two connected gears. It takes the number of teeth on both gears and calculates how many revolutions the second gear makes. I also used a boolean variable to determine the direction each gear is turning.

Java Code

Sample Input

6 12 3 true

Sample Output

1.0 false

What I Used

  • Scanner for input
  • int and double variables
  • boolean values and ! operator to reverse booleans
  • System.out.println()
  • Arithmetic operations with gears
