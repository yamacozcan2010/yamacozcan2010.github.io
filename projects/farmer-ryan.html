In this project, the program reads the number of beans in six bags, adds them together, and prints the total number of beans Ryan has to plant.

Java Code

Sample Input

241 675 897 12 4354 7625

Sample Output

Ryan has to plant 13804 beans

What I Used

  • System.out.println()
