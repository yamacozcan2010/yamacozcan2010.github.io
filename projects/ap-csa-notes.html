Unit 1 Notes

Part 1 - Java Basics

Algorithms and Java Structure

  • An algorithm is a step by step process used to solve a problem or complete a task.
  • Sequencing means doing the steps in a specific order.
  • An IDE is a program used to write, compile, and run code.
  • Java programs are written inside classes.
  • The main method is usually where the program starts running.
public class MyClass {
    public static void main(String[] args) {
        System.out.println("Hello!");
    }
}
  • Most Java statements end with a semicolon.
  • Curly brackets { } are used to group blocks of code.
  • // and /* */ are used for comments.
  • A compiler translates Java code into something the computer can execute.

Variables and Data Types

  • A variable stores a value in memory.
  • Every variable has a name and a data type.
  • A data type tells Java what kind of value the variable can store.
int score;
double gpa = 3.5;
  • int is used for whole numbers.
  • double is used for decimal numbers.
  • boolean stores true or false.
  • String is a reference type used for text.

Printing and Literals

  • System.out.print() prints without moving to a new line.
  • System.out.println() prints and then moves to the next line.
  • A literal is a fixed value written directly in the code.
  • A string literal is text inside double quotes.
System.out.println("Hello");
  • \" is used for a double quote inside a string.
  • \\ is used for a backslash.
  • \n starts a new line.

Arithmetic

  • Java uses +, -, *, /, and % for arithmetic.
  • % gives the remainder after division.
  • When two ints are divided, the decimal part is removed number isnt rounded.
  • If at least one value is a double, the result is a double.
5 / 2      // 2
5.0 / 2    // 2.5
7 % 3      // 1

Order of Operations

  • Parentheses are evaluated first.
  • Then *, /, and %.
  • Then + and -.
  • Operators with the same priority are evaluated from left to right.

Errors

  • A syntax error means the code breaks Java's grammar rules.
  • A logic error means the program runs but gives the wrong result.
  • A run-time error happens while the program is running.
  • An exception is a run-time error that interrupts the program.
  • Dividing an integer by zero causes an ArithmeticException.

Part 2 - Variables, Casting, Libraries, and Comments

Assignment and Expressions

  • = is used to give a variable a value or change its value.
  • The value on the right side is stored in the variable on the left.
  • A variable must have a value before it can be used.
  • The first value assigned to a variable is its initialization.
  • null means a reference variable is not connected to any object.
  • An expression is evaluated to produce one final value.
  • The type of the result depends on the values and operators used.
  • Scanner can be used for keyboard input, although keyboard input is not tested on the AP exam.
int score = 10;
score = 20;

Type Casting

  • Type casting converts a value from one data type to another.
  • (int) converts a double to an int.
  • (double) converts an int to a double.
  • Converting a double to an int removes the decimal part. It does not round.
double x = 5.8;
int y = (int)x;   // 5

int a = 4;
double b = (double)a;   // 4.0
  • Ints can automatically be converted to doubles when needed.
  • If an expression contains a double, the result will usually become a double.
  • A positive double can be rounded using (int)(x + 0.5).
  • For negative values, (int)(x - 0.5) can be used.

Integer Limits and Round-Off

  • Integer.MAX_VALUE is the largest possible int value.
  • Integer.MIN_VALUE is the smallest possible int value.
  • Ints use a limited amount of memory, so they have a fixed range.
  • If a calculation goes outside that range, integer overflow happens.
  • The result after overflow may be completely different from what was expected.
  • Doubles also have limited precision.
  • Some decimal values cannot be stored perfectly, which can cause round-off errors.
  • Using ints or rounding doubles can help avoid unwanted precision problems.

Compound Assignment Operators

  • +=, -=, *=, /=, and %= are shortcuts for updating a variable.
int x = 5;

x += 3;   // same as x = x + 3
x *= 2;   // same as x = x * 2
  • ++ adds 1 to a variable.
  • -- subtracts 1 from a variable.
x++;
x--;

Libraries, APIs, and Classes

  • Libraries are collections of classes written by other programmers.
  • An API explains how to use the classes in a library.
  • Documentation is used to understand what a class contains and what it can do.
  • Classes are grouped into packages.
  • A class defines a reference type and can be used to create objects.
  • Attributes are the data connected to a class and are stored in variables.
  • Behaviors are what objects can do and are defined by methods.

Comments

  • Comments are used to explain code.
  • They are ignored by the compiler and are not executed.
  • // is used for one-line comments.
  • /* */ is used for block comments.
  • /** */ is used for Javadoc comments and API documentation.

Preconditions and Postconditions

  • A precondition is something that must be true before a section of code runs.
  • The method usually assumes that the precondition is already true.
  • A postcondition is something that should be true after the code finishes running.
  • Postconditions describe the result, such as a returned value or the final state of an object.

Part 3 - Methods

Methods and Procedural Abstraction

  • A method is a named block of code that only runs when it is called.
  • A block of code is code inside braces { }.
  • Methods are useful for avoiding repeated code.
  • Procedural abstraction means you can use a method by knowing what it does without needing to know exactly how it was written.

Method Calls

  • When a method is called, normal sequential execution is temporarily interrupted.
  • The program jumps to the method and runs its statements.
  • When the method finishes, the program goes back to the line immediately after the method call.
  • A return statement can also end the method and send control back.

Parameters and Arguments

  • A parameter is a variable written in the method header.
  • Parameters can be used inside the method.
  • An argument is the actual value passed into the method when it is called.
public static void greet(String name) {
    System.out.println("Hello " + name);
}

greet("Yamac");
  • In this example, name is the parameter.
  • "Yamac" is the argument.
  • The number, order, and types of arguments have to match the parameters.

Call by Value

  • Java passes arguments using call by value.
  • This means the parameter receives a copy of the argument's value.

Method Signatures

  • A method signature includes the method name and the ordered list of parameter types.
  • A method without parameters still has a signature with an empty parameter list.
print(int x)
print(String x)

Method Overloading

  • Methods can have the same name if they have different signatures.
  • This is called method overloading.
  • The parameter types or number of parameters have to be different.
