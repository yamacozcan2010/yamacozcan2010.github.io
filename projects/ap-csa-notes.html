1.1 Introduction to Java

Algorithms and Java Basics

  • An algorithm is a step-by-step process used to solve a problem.
  • Sequencing means performing steps in a specific order.
  • An IDE provides tools to write, compile, and run code.
  • Java programs are organized into classes, and execution usually starts in the main method.
public class MyClass {
    public static void main(String[] args) {
        System.out.println("Hello!");
    }
}
  • Java code is written inside classes.
  • The main method is usually where the program starts.
  • Most statements end with a semicolon.
  • Curly brackets are used to group code.

Variables

  • Variables store values that can change while the program runs.
  • int is for whole numbers.
  • double is for decimal numbers.
  • boolean is true or false.
  • String is used for text.
int score;
double gpa = 3.5;

Printing

  • System.out.print() stays on the same line.
  • System.out.println() moves to a new line after printing.

Arithmetic

  • + - * / work like normal math.
  • % gives the remainder after division.
  • int divided by int gives an int, so the decimal part is removed.
  • If one of the numbers is a double, the answer will be a double.
5 / 2    // 2
5.0 / 2  // 2.5
7 % 3    // 1

Order of Operations

  • Parentheses first.
  • Then *, / and %.
  • Then + and -.
  • Same priority goes from left to right.

Errors

  • Syntax error = code is written incorrectly.
  • Logic error = code runs but gives the wrong result.
  • Run-time error = something goes wrong while the program is running.
